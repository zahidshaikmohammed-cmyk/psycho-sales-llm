## 1.8.1 Memory

## 1. Purpose
Explain how information and experience can be retained and later used.

## 2. Definition
Memory is the set of processes and capacities through which information is encoded, retained, and later retrieved or expressed.

## 3. Core Understanding
Memory is not a single storage container. It includes interacting processes of encoding, retention, consolidation, retrieval, updating, and use. Different forms of memory differ in duration, content, accessibility, and dependence on conscious recollection.

### Mechanism
Memory performance depends on what was attended to and encoded, how information was stabilized and integrated, what cues are available later, and what competing information is active at retrieval. Successful retrieval does not require a literal replay of the original event; remembered content can be reconstructed from stored information, contextual cues, and current knowledge.

### Boundary conditions
Memory performance varies with attention, motivation, emotional state, sleep, delay, interference, context, and task demands. A failure to remember at one moment does not necessarily mean that the information was never learned or that it has been permanently erased.

### Evidence status
Memory is supported by extensive experimental, cognitive, neuropsychological, and neuroscientific evidence, but no single model fully captures every memory system or process.

## 4. Relationship to This Chapter
Memory is the chapter-level construct that organizes encoding, storage, retrieval, memory systems, forgetting, errors, and personal and clinical manifestations.

## 5. Boundaries
### Owns
Owns memory as the general psychological capacity and process family for retaining and using information from past experience.

### Defers
Specific encoding, storage, retrieval, consolidation, memory-system, forgetting, error, and clinical constructs have dedicated Topics.

## 6. Key Principles
- Memory is a collection of interacting processes, not a single mechanism.
- Remembering depends on both retained information and retrieval conditions.
- Retrieval can preserve, transform, or update remembered information.

## 1.8.2 Encoding

## 1. Purpose
Explain how information becomes represented in a form that can later support memory.

## 2. Definition
Encoding is the set of processes through which information is transformed into representations that can contribute to subsequent memory.

## 3. Core Understanding
Encoding is selective rather than a complete recording of experience. Attention, prior knowledge, goals, meaning, perceptual characteristics, and processing depth influence what information receives effective encoding.

### Mechanism
Encoding can involve perceptual analysis, semantic interpretation, association with existing knowledge, organization, and elaboration. The resulting representation need not preserve every feature of the original event. Deeper or more meaningful processing often improves later memory, but the useful form of processing depends on the material and the retrieval task.

### Boundary conditions
Information can be present in the environment without being effectively encoded. Attention failure can therefore produce later forgetting that reflects weak initial encoding rather than rapid loss after learning.

### Related concepts
Encoding precedes storage and retrieval but is distinct from them. Retrieval success is not a direct measure of encoding quality because poor retrieval cues can obscure information that was adequately encoded.

## 4. Relationship to This Chapter
Encoding is the first major process in the memory architecture: information must be represented before later retention and retrieval can occur.

## 5. Boundaries
### Owns
Owns formation and transformation of memory representations at acquisition.

### Defers
Storage and consolidation concern subsequent retention and stabilization; levels of processing specializes one class of encoding differences.

## 6. Key Principles
- Encoding determines what information becomes available for later memory.
- Encoding is selective and shaped by attention, meaning, and prior knowledge.
- Poor retrieval does not by itself prove poor encoding.

## 1.8.3 Storage

## 1. Purpose
Explain the retention of information after initial encoding.

## 2. Definition
Storage is the persistence of encoded information or its underlying representation across time.

## 3. Core Understanding
Storage refers to retention, not simply the subjective feeling that something is remembered. Retained information can remain inaccessible under some conditions and become retrievable when appropriate cues are available.

### Mechanism
Retention depends on changes and relationships established during and after encoding. Different memory systems have different retention characteristics, and stabilization can involve consolidation. Storage therefore should not be treated as a single physical location or a passive warehouse.

### Boundary conditions
Retention is influenced by time, interference, rehearsal, consolidation, sleep, context, and later learning. Apparent forgetting may reflect retrieval failure rather than complete loss of stored information.

### Evidence status
Evidence from behavioral, neuropsychological, and neuroscientific work supports multiple forms of retention and stabilization, while the exact physical and computational implementation of every memory trace remains an active scientific question.

## 4. Relationship to This Chapter
Storage occupies the retention stage between encoding and later retrieval and connects short-lived and long-lasting memory systems.

## 5. Boundaries
### Owns
Owns persistence of encoded information across time as a general memory process.

### Defers
Consolidation owns stabilization processes; long-term memory owns the long-duration memory system; forgetting owns loss or inaccessibility phenomena.

## 6. Key Principles
- Storage concerns retention across time.
- Stored information can be temporarily inaccessible.
- Retention differs across memory systems and is affected by subsequent experience.

## 1.8.4 Retrieval

## 1. Purpose
Explain how previously encoded information becomes accessible for current use.

## 2. Definition
Retrieval is the process of accessing or expressing information from memory in response to a current task or cue.

## 3. Core Understanding
Retrieval is an active process rather than a simple readout. Current goals, cues, context, competing memories, and reconstruction can influence what is recovered and how it is expressed.

### Mechanism
A cue activates potentially relevant memory representations, which are selected, evaluated, and brought into a usable form. Retrieval can be successful even when recall is incomplete, and recognition can provide stronger support than unaided recall because the environment supplies additional information.

### Retrieval versus storage
Failure to retrieve does not establish that the information is absent. Conversely, fluent retrieval does not guarantee that the memory is accurate.

### Consequences
Retrieval can strengthen later accessibility through retrieval practice, but retrieving information can also alter subsequent memory under some conditions.

## 4. Relationship to This Chapter
Retrieval is the memory process that connects retained information to present performance, recollection, recognition, and memory-based action.

## 5. Boundaries
### Owns
Owns access to retained information during remembering.

### Defers
Recognition and recall specialize retrieval formats; retrieval practice specializes repeated retrieval as a learning technique.

## 6. Key Principles
- Retrieval depends strongly on available cues and current context.
- Retrieval failure is not identical to storage failure.
- Remembering can itself change later memory.

## 1.8.5 Consolidation

## 1. Purpose
Explain processes through which newly formed memories become more stable or integrated over time.

## 2. Definition
Consolidation refers to processes that stabilize and, in some cases, reorganize newly acquired memory representations after initial encoding.

## 3. Core Understanding
Consolidation is not simply passive strengthening. Different forms and timescales have been proposed, including early stabilization and longer-term systems-level reorganization.

### Mechanism
New memories can initially be vulnerable to disruption and may become more stable through post-learning biological and cognitive processes. Sleep, repeated reactivation, and interaction with existing knowledge can contribute to some forms of consolidation, although effects depend on memory type and task.

### Boundary conditions
Consolidation should not be treated as a universal single-stage process. Some memories stabilize rapidly, while others continue to change as they interact with later experience.

### Evidence status
The existence of post-encoding stabilization is well supported. The precise mechanisms and extent of systems-level reorganization vary across memory types and remain topics of active research.

## 4. Relationship to This Chapter
Consolidation explains how memories change after encoding and helps connect immediate memory formation with longer-term retention.

## 5. Boundaries
### Owns
Owns post-encoding stabilization and integration of memories.

### Defers
Reconsolidation concerns updating after retrieval; sleep-related memory effects are treated through the memory-centered Topic **Sleep and memory**.

## 6. Key Principles
- Newly formed memories can change after initial encoding.
- Consolidation is time-dependent and memory-system dependent.
- Stabilization does not imply permanent immutability.

## 1.8.6 Reconsolidation

## 1. Purpose
Explain how retrieved memories can become temporarily modifiable and subsequently restabilize.

## 2. Definition
Reconsolidation is a process in which a previously consolidated memory, after retrieval under conditions that destabilize it, can become modifiable before being restabilized.

## 3. Core Understanding
Retrieval does not always leave a memory unchanged. Under particular conditions, reactivation can create a period during which subsequent information, learning, or interference can influence the later expression of the memory.

### Mechanism
A retrieved representation may enter a labile state, followed by processes that restabilize it. The conditions required for destabilization are not identical for all memories and may depend on prediction error, age, strength, context, and other factors.

### Boundary conditions
Simple recall does not automatically imply that reconsolidation occurred. Experimental paradigms differ in how strongly they demonstrate destabilization and subsequent modification.

### Evidence status
Reconsolidation has substantial experimental support, especially in animal and controlled human paradigms, but its boundaries and translation to complex autobiographical memories remain actively studied.

## 4. Relationship to This Chapter
Reconsolidation extends the chapter's process model by showing that retrieval can be followed by memory updating rather than merely access.

## 5. Boundaries
### Owns
Owns post-retrieval destabilization and restabilization of previously consolidated memories.

### Defers
Memory reconstruction and false memory address broader reconstructive processes; consolidation addresses initial stabilization.

## 6. Key Principles
- Some retrieved memories can become temporarily modifiable.
- Reconsolidation depends on specific conditions rather than retrieval alone.
- Human autobiographical memory cannot be assumed to follow simple laboratory reconsolidation paradigms.

## 1.8.7 Levels of processing

## 1. Purpose
Explain why the manner in which information is processed during encoding influences later memory.

## 2. Definition
Levels of processing is the framework proposing that memory depends partly on the depth and nature of processing applied to information during encoding.

## 3. Core Understanding
Shallow processing emphasizes relatively physical or surface characteristics, whereas deeper processing emphasizes meaning and relationships. Meaningful processing often produces better later memory because it creates richer and more distinctive representations.

### Mechanism
Processing that connects new information with meaning, prior knowledge, and elaborated relationships can provide multiple routes for later retrieval. The framework is not a claim that all forms of deeper processing are universally superior under every test condition.

### Evidence status
Depth-of-processing effects are well established, while later research has shown that the quality and match of encoding to retrieval demands matter in addition to a simple shallow-to-deep continuum.

### Misconception
"Deep" processing should not be treated as a single mental action or a guarantee of better memory regardless of task.

## 4. Relationship to This Chapter
This Topic explains an important determinant of encoding quality within the broader memory architecture.

## 5. Boundaries
### Owns
Owns the processing-depth account of encoding differences.

### Defers
Encoding owns the general acquisition process; encoding specificity explains compatibility between encoding and retrieval conditions.

## 6. Key Principles
- Meaningful processing often supports stronger later memory.
- Processing depth is not the only determinant of retrieval success.
- Encoding effectiveness depends partly on later retrieval demands.

## 1.8.8 Chunking

## 1. Purpose
Explain how grouping information can reduce the effective number of separate units that must be handled.

## 2. Definition
Chunking is the organization of multiple elements into meaningful units that can be processed or remembered as larger structured groups.

## 3. Core Understanding
A chunk is defined by organization, not by a fixed number of items. Familiar knowledge allows a person to treat several elements as one meaningful unit, reducing the apparent burden on limited-capacity processing systems.

### Mechanism
Chunking combines elements according to learned patterns, categories, sequences, or meaningful structures. For an expert, a complex pattern may constitute one recognizable unit even though a novice experiences its components separately.

### Boundary conditions
Chunking depends on existing knowledge and task structure. It does not abolish underlying information limits; it changes how information is represented and organized.

### Example
A familiar telephone number format can be represented as a few grouped units rather than many independent digits.

## 4. Relationship to This Chapter
Chunking is a memory-supporting organization process that links encoding, working memory, and retrieval.

## 5. Boundaries
### Owns
Owns grouping of information into meaningful memory units.

### Defers
Working-memory capacity owns broader capacity constraints; expertise development owns the acquisition of domain-specific chunk structures.

## 6. Key Principles
- Meaningful grouping changes the effective unit structure of information.
- Chunking depends on knowledge and organization.
- Experts often possess richer chunk structures than novices.

## 1.8.9 Retrieval cues

## 1. Purpose
Explain information that helps activate or access a stored memory.

## 2. Definition
A retrieval cue is a stimulus, context, thought, or internal state that increases access to particular information in memory.

## 3. Core Understanding
Retrieval cues work by overlapping with or reinstating aspects of the information and conditions associated with learning. A cue can therefore make one memory accessible while leaving another relatively inaccessible.

### Mechanism
Cues narrow the search space of memory. Their effectiveness depends on diagnosticity: a cue shared by many memories is less specific than one strongly associated with a particular event or fact.

### Boundary conditions
The same cue can help or interfere depending on which memories it activates. Retrieval can also be biased by the person's current goals and expectations.

### Related concepts
Encoding specificity and context-dependent memory describe important cases in which the compatibility between cues and encoding conditions affects retrieval.

## 4. Relationship to This Chapter
Retrieval cues are a central bridge between stored information and successful remembering.

## 5. Boundaries
### Owns
Owns the general role of cues in facilitating or guiding retrieval.

### Defers
Encoding specificity owns encoding–retrieval compatibility; context- and state-dependent memory specialize particular cue conditions.

## 6. Key Principles
- Retrieval cues guide access rather than reproduce memories automatically.
- Diagnostic cues can improve specificity of retrieval.
- Cue effectiveness depends on the memory and retrieval context.

## 1.8.10 Encoding specificity

## 1. Purpose
Explain why memory retrieval is often better when retrieval conditions overlap with conditions present during encoding.

## 2. Definition
Encoding specificity is the principle that successful retrieval depends partly on the compatibility between information encoded with an experience and cues available during later retrieval.

## 3. Core Understanding
Memory is encoded together with aspects of the surrounding situation, internal state, task, and meaning. Later cues that reinstate relevant features can therefore improve access.

### Mechanism
Encoding creates associations between target information and contextual or conceptual features. Retrieval becomes more effective when the test supplies cues that match those encoded associations.

### Boundary conditions
Encoding specificity does not mean exact environmental replication is always necessary. Conceptual and semantic overlap can matter as much as physical context, and distinctive cues can sometimes compensate for contextual differences.

### Misconception
It is not a claim that memory is retrieved only in the original environment.

## 4. Relationship to This Chapter
This Topic provides a general principle linking encoding and retrieval and prepares the more specific Topics on context- and state-dependent memory.

## 5. Boundaries
### Owns
Owns the general encoding–retrieval compatibility principle.

### Defers
Context-dependent memory and state-dependent memory are specific manifestations; retrieval cues owns the broader cue mechanism.

## 6. Key Principles
- Retrieval improves when available cues match encoded information.
- Matching can be conceptual, contextual, or state-related.
- Exact environmental repetition is not required.

## 1.8.11 Sensory memory

## 1. Purpose
Explain very brief retention of sensory information immediately after stimulation.

## 2. Definition
Sensory memory is a short-lived form of memory that preserves information from sensory input for a brief period after the physical stimulus has ended.

## 3. Core Understanding
Sensory memory preserves relatively detailed sensory information long enough for subsequent selection and processing. Its duration and characteristics differ across sensory modalities.

### Mechanism
A stimulus leaves a transient representation that can support perceptual continuity and selection before rapidly fading or being overwritten. Iconic and echoic memory are major modality-specific forms.

### Boundary conditions
Sensory persistence should not be confused with conscious perception or durable memory. A person may have brief sensory information available without intentionally remembering it.

### Evidence status
Brief sensory persistence is strongly supported by classic experimental paradigms, although terminology and theoretical interpretations vary across modalities and tasks.

## 4. Relationship to This Chapter
Sensory memory forms the earliest memory layer in the chapter's memory-system architecture.

## 5. Boundaries
### Owns
Owns brief retention of sensory information following stimulation.

### Defers
Iconic and echoic memory specialize visual and auditory forms; attention and perception own selection and perceptual organization.

## 6. Key Principles
- Sensory memory is brief and modality-dependent.
- It can preserve more detail than later memory systems.
- Brief sensory persistence is not the same as durable remembering.

## 1.8.12 Iconic memory

## 1. Purpose
Explain brief visual persistence after visual stimulation.

## 2. Definition
Iconic memory is the very short-lived visual form of sensory memory that preserves information from a visual stimulus after the stimulus disappears.

## 3. Core Understanding
Iconic memory can retain a relatively detailed visual representation for a fraction of a second, allowing information to remain available briefly after physical input ends.

### Mechanism
Visual information persists transiently before rapidly decaying or being replaced by new input. Classic partial-report experiments demonstrated that more visual information can be briefly available than can normally be reported after a delay.

### Boundary conditions
Iconic memory is not equivalent to a conscious visual image held for an extended period. Attention and later selection determine which portions become available to longer-lasting systems.

### Evidence status
The phenomenon is well established, although exact estimates of duration depend on stimulus properties and experimental method.

## 4. Relationship to This Chapter
Iconic memory is the visual specialization of sensory memory.

## 5. Boundaries
### Owns
Owns brief visual sensory retention.

### Defers
Sensory memory is the broader modality-general category; visual perception owns perceptual processing.

## 6. Key Principles
- Iconic memory is extremely brief.
- It preserves visual information beyond stimulus offset.
- Attention determines which information proceeds into later processing.

## 1.8.13 Echoic memory

## 1. Purpose
Explain brief auditory persistence after sounds end.

## 2. Definition
Echoic memory is the brief auditory form of sensory memory that retains information from recently presented sounds.

## 3. Core Understanding
Auditory information can remain temporarily available after the physical sound has ended, supporting continuity of speech and other auditory sequences.

### Mechanism
Transient auditory representations persist long enough to allow subsequent processing and integration of sequential sound information. Duration is generally longer than the persistence of iconic visual information, although estimates vary with stimulus and task.

### Boundary conditions
Echoic memory is not the same as understanding or consciously recalling a spoken message. Longer-lasting auditory memory requires further encoding and processing.

### Evidence status
Brief auditory persistence is supported by experimental research, with duration varying according to stimulus properties, modality, and measurement method.

## 4. Relationship to This Chapter
Echoic memory is the auditory specialization of sensory memory.

## 5. Boundaries
### Owns
Owns brief retention of auditory sensory information.

### Defers
Sensory memory is the broader category; phonological loop concerns active maintenance in working memory.

## 6. Key Principles
- Echoic memory briefly preserves auditory information.
- It supports processing of sequential sound.
- It should not be confused with durable verbal memory.

## 1.8.14 Short-term memory

## 1. Purpose
Explain temporary retention of information over a short interval.

## 2. Definition
Short-term memory is a limited-duration memory system for maintaining information over brief periods when it is no longer continuously available in the environment.

## 3. Core Understanding
Short-term memory is often described as a temporary store, but modern accounts emphasize active maintenance, attention, and interaction with working memory rather than a simple passive container.

### Mechanism
Information can remain temporarily accessible through attention, rehearsal, or active maintenance. Without sufficient maintenance or further encoding, accessibility typically declines rapidly.

### Boundary conditions
Short-term retention varies with interference, similarity among items, meaningful organization, and task demands. Capacity is not a single universal item count because chunking and representation alter effective unit size.

### Related concepts
Working memory includes temporary maintenance plus manipulation and control, making it broader functionally than simple short-term retention.

## 4. Relationship to This Chapter
Short-term memory represents brief retention and provides a bridge between sensory input and longer-term memory.

## 5. Boundaries
### Owns
Owns short-duration retention of information.

### Defers
Working memory owns active maintenance/manipulation; long-term memory owns durable retention.

## 6. Key Principles
- Short-term memory is temporary and capacity-limited.
- Active maintenance can preserve information.
- Capacity depends on representation and organization, not a fixed universal item count.

## 1.8.15 Working memory

## 1. Purpose
Explain the limited-capacity system used to temporarily maintain and manipulate information during ongoing cognition.

## 2. Definition
Working memory is a limited-capacity cognitive system that temporarily maintains and manipulates information while coordinating current tasks.

## 3. Core Understanding
Working memory is more than passive short-term storage. It supports reasoning, comprehension, planning, problem solving, and goal-directed behavior by keeping task-relevant information available while it is transformed or integrated.

### Mechanism
Working-memory performance depends on attention, active maintenance, interference control, updating, and coordination of information. Multiple components can support different forms of information processing.

### Boundary conditions
Capacity varies with task complexity, familiarity, strategy, distraction, and individual differences. Poor performance can reflect interference or control demands rather than a simple absence of storage capacity.

### Evidence status
Working memory is strongly supported as a useful functional construct, while the precise architecture and independence of its components remain debated.

## 4. Relationship to This Chapter
Working memory is a central memory system linking temporary information maintenance with attention and higher cognition.

## 5. Boundaries
### Owns
Owns active temporary maintenance and manipulation.

### Defers
Its components have dedicated Topics; executive attention and broader executive functions belong to Chapters 1.6 and 1.9.

## 6. Key Principles
- Working memory maintains information for current cognitive operations.
- It is limited and vulnerable to interference.
- Maintenance and manipulation are distinct from long-term storage.

## 1.8.16 Working-memory capacity

## 1. Purpose
Explain individual and task-related limits on maintaining and manipulating information.

## 2. Definition
Working-memory capacity is the amount or complexity of information that can be actively maintained and manipulated under specified task conditions.

## 3. Core Understanding
Capacity is not a single fixed number. Performance depends on representation, attention, interference, task demands, strategies, and prior knowledge.

### Measurement
Complex span, operation span, reading span, change-detection, and related tasks capture partly different aspects of limited-capacity processing. Scores should therefore not be treated as interchangeable measures of one literal storage container.

### Mechanism
Capacity limits constrain simultaneous processing, especially when information must be maintained while competing operations occur. Knowledge and chunking can expand effective performance without necessarily increasing basic storage capacity.

### Evidence status
Individual differences in working-memory performance are reliable and related to several cognitive outcomes, but the exact nature of the underlying capacity limitation remains theoretically contested.

## 4. Relationship to This Chapter
This Topic specializes the capacity constraints of working memory within the broader memory architecture.

## 5. Boundaries
### Owns
Owns capacity limitations and their measurement in working memory.

### Defers
Working memory owns the broader system; chunking and attention explain mechanisms that can alter apparent capacity.

## 6. Key Principles
- Working-memory capacity is task- and representation-dependent.
- Effective capacity can be improved by organization and knowledge.
- Different capacity tasks measure overlapping but nonidentical functions.

## 1.8.17 Central executive

## 1. Purpose
Explain the control component proposed to coordinate attention and processing within working memory.

## 2. Definition
The central executive is a theoretical working-memory component responsible for coordinating, allocating, and controlling attention across competing processing demands.

## 3. Core Understanding
The central executive is not best understood as a single miniature decision-maker. It is a functional construct used to explain control operations such as directing attention, switching between tasks, updating relevant information, and coordinating other working-memory processes.

### Theory / Model
In Baddeley's working-memory framework, the central executive coordinates the system while specialized storage components support particular information types.

### Evidence status
Executive-control functions are strongly supported, but whether they reflect one unitary mechanism or multiple control processes remains debated.

## 4. Relationship to This Chapter
The central executive explains how working memory can coordinate information rather than merely hold it.

## 5. Boundaries
### Owns
Owns the central-control component within the canonical working-memory model.

### Defers
Executive attention and cognitive control are broader constructs; phonological loop, visuospatial sketchpad, and episodic buffer own specialized working-memory components.

## 6. Key Principles
- The central executive is a theoretical control component.
- It coordinates rather than simply stores information.
- Its internal architecture is not fully settled.

## 1.8.18 Phonological loop

## 1. Purpose
Explain temporary maintenance of verbal and speech-based information in working memory.

## 2. Definition
The phonological loop is a proposed working-memory system that temporarily maintains speech-based and phonological information.

## 3. Core Understanding
The phonological loop is commonly described as involving temporary phonological storage supported by rehearsal. It helps maintain verbal sequences long enough for comprehension, learning, and other cognitive operations.

### Mechanism
Speech-based information can be represented in a phonological form and refreshed through subvocal rehearsal. Similar-sounding material can interfere because competing representations overlap.

### Evidence
Effects such as phonological similarity, irrelevant speech, and articulatory suppression have provided evidence for specialized verbal working-memory processes.

### Boundary conditions
The loop is not a complete theory of language or verbal long-term memory. Meaningful knowledge can support performance beyond what phonological storage alone predicts.

## 4. Relationship to This Chapter
It is a specialized component of working memory concerned with verbal and auditory information.

## 5. Boundaries
### Owns
Owns temporary phonological maintenance within working memory.

### Defers
Language processing belongs to Chapter 1.11; semantic and episodic long-term memory have separate Topics.

## 6. Key Principles
- Verbal information can be temporarily maintained in phonological form.
- Rehearsal supports continued accessibility.
- Phonological similarity creates interference.

### Mechanism
Binding allows separate features and information sources to be represented as a structured episode or meaningful unit. This can support comprehension and integration across working memory and long-term memory.

### Theory / Model
The episodic buffer was introduced into Baddeley's model to address integration problems not fully explained by the earlier components.

### Evidence status
The construct is influential, but its precise mechanisms and relation to broader binding and working-memory processes remain theoretically debated.

## 1.8.21 Long-term memory

## 1. Purpose
Explain memory that remains available beyond the brief limits of sensory and short-term systems.

## 2. Definition
Long-term memory is the memory system comprising information that can remain accessible over extended periods, from minutes and days to years or a lifetime.

## 3. Core Understanding
Long-term memory contains multiple forms with different contents and retrieval properties. It is not a single uniform store.

### Types
Long-term memory includes declarative and nondeclarative forms, with episodic, semantic, procedural, priming, conditioning, and other specialized forms differing in how they are acquired and expressed.

### Mechanism
Long-term retention depends on encoding, consolidation, association, retrieval pathways, and subsequent experience. Memories can be stable while still remaining modifiable.

### Boundary conditions
Duration alone does not determine memory type. A memory can last a long time without being consciously recollected.

## 4. Relationship to This Chapter
Long-term memory organizes the durable memory systems that follow the temporary-memory architecture.

## 5. Boundaries
### Owns
Owns the broad long-duration memory system.

### Defers
Specific declarative, procedural, priming, conditioning, autobiographical, and prospective forms have dedicated Topics.

## 6. Key Principles
- Long-term memory contains multiple systems and forms.
- Durable memory is not necessarily consciously accessible.
- Long-term retention does not imply complete immutability.

## 1.8.22 Explicit memory

Explain memory that can be intentionally brought to conscious awareness.

## 2. Definition
Explicit memory is memory that is consciously accessible and can be intentionally reported or used as remembered information.

## 3. Core Understanding
Explicit memory commonly includes remembering events and facts. Its expression depends on retrieval conditions and can be influenced by reconstruction and confidence.

Episodic and semantic memory are major forms of explicit memory, although the boundary between forms can vary with task and theoretical framework.

### Boundary conditions
Conscious accessibility does not guarantee accuracy. People can confidently report memories that contain distortions or source errors.

### Evidence status
The distinction between consciously accessible and nonconsciously expressed memory is supported by converging behavioral and neuropsychological evidence, although terminology differs across traditions.

## 4. Relationship to This Chapter
Explicit memory organizes conscious forms of long-term remembering.

## 5. Boundaries
### Owns
Owns consciously accessible long-term memory as a category.

### Defers
Episodic and semantic memory specify major explicit forms; implicit memory covers nonconscious expression.

## 6. Key Principles
- Explicit memory involves conscious accessibility.
- Conscious accessibility is not the same as accuracy.
- Episodic and semantic memory are major explicit forms.

## 1.8.23 Implicit memory

## 1. Purpose
Explain memory expressed through performance or processing without requiring conscious recollection.

## 2. Definition
Implicit memory is the influence of prior experience on subsequent behavior or processing when explicit conscious recollection is not required.

## 3. Core Understanding
Prior learning can alter performance even when a person cannot intentionally report the relevant learning episode. Priming, procedural learning, and some forms of conditioning can produce such effects.

### Mechanism
Previous exposure can alter activation, response tendencies, perceptual processing, or learned associations. The resulting influence can occur without deliberate retrieval of the original experience.

### Boundary conditions
Absence of reported recollection does not automatically prove that a process is unconscious. Explicit and implicit measures can dissociate, but the interpretation of such dissociations requires careful task analysis.

## 4. Relationship to This Chapter
Implicit memory complements explicit memory by identifying long-term effects that do not depend on conscious remembering.

## 5. Boundaries
### Owns
Owns nonconsciously expressed memory effects as a broad category.

### Defers
Priming, procedural memory, and conditioning memory specialize important forms; consciousness belongs to Chapter 1.5.

## 1.8.24 Declarative memory

## 1. Purpose
Explain long-term memory for information that can generally be consciously stated or described.

## 2. Definition
Declarative memory is long-term memory for facts and events that can generally be consciously recollected and verbally or otherwise explicitly represented.

## 3. Core Understanding
Declarative memory includes semantic knowledge and episodic memories. It is often contrasted with nondeclarative memory, which can be expressed through performance without conscious recollection.

### Mechanism
Declarative memories depend on encoding, consolidation, retrieval, and integration with existing knowledge. They can be richly structured but remain vulnerable to distortion and retrieval errors.

### Boundary conditions
The ability to describe a memory does not guarantee literal accuracy. Likewise, some knowledge becomes highly automatic in use while retaining a declarative origin.

## 4. Relationship to This Chapter
Declarative memory organizes the explicit long-term memory system containing facts and events.

## 5. Boundaries
### Owns
Owns the fact-and-event class of long-term memory.

### Defers
Episodic and semantic memory are its major forms; procedural and other nondeclarative systems are separate.

## 6. Key Principles
- Declarative memory supports conscious knowledge of facts and events.
- It includes episodic and semantic forms.
- Declarative memories can be reconstructed and distorted.

## 1.8.25 Nondeclarative memory

## 1. Purpose
Explain long-term learning expressed through performance rather than conscious recollection.

## 2. Definition
Nondeclarative memory is a category of long-term memory expressed through changes in performance, processing, or behavior without requiring conscious recollection of the learning episode.

## 3. Core Understanding
Nondeclarative memory encompasses several mechanisms rather than one unified system, including procedural learning, priming, and conditioning.

### Mechanism
Repeated practice can alter skills; prior exposure can change processing; and learned associations can alter responding. These effects can persist even when explicit recall of the acquisition episode is weak.

### Boundary conditions
"Nondeclarative" does not mean every component is permanently unconscious. Some associated knowledge can become consciously accessible, and awareness can vary with task demands.

### Evidence status
Dissociations between explicit and performance-based memory measures support the category, while the extent to which its forms share mechanisms remains debated.

## 4. Relationship to This Chapter
Nondeclarative memory provides the complementary category to declarative memory.

## 5. Boundaries
### Owns
Owns the broad category of long-term memory expressed without required conscious recollection.

### Defers
Procedural memory, priming, and conditioning memory specify major forms.

## 6. Key Principles
- Nondeclarative memory is expressed through performance or processing.
- It includes multiple mechanisms.
- Lack of conscious recall does not mean lack of learning.

## 1.8.26 Episodic memory

## 1. Purpose
Explain memory for personally experienced events situated in time and place.

## 2. Definition
Episodic memory is memory for personally experienced events together with contextual information about when, where, or how they occurred.

## 3. Core Understanding
Episodic remembering typically involves mentally accessing an event as something that happened to the individual. It can include perceptual, emotional, spatial, temporal, and contextual details.

### Mechanism
Event memories are constructed from encoded features and later retrieved using cues. Recollection is therefore vulnerable to omissions, substitutions, source errors, and incorporation of later information.

### Boundary conditions
Episodic memory differs from general factual knowledge even though the two can interact. Repeatedly recalling an event can alter its later representation.

### Evidence status
The distinction between episodic and semantic memory is influential and supported by behavioral and neuropsychological findings, while their exact independence remains debated.

## 4. Relationship to This Chapter
Episodic memory is the event-based branch of declarative memory and is central to autobiographical remembering.

## 5. Boundaries
### Owns
Owns memory for personally experienced events with contextual specificity.

### Defers
Autobiographical memory concerns personally relevant memory more broadly; recollection and source memory specialize retrieval characteristics.

## 6. Key Principles
- Episodic memory represents experienced events in context.
- Recollection is reconstructive.
- Event memory can be altered by later information.

## 1.8.27 Semantic memory

Explain memory for general facts, meanings, concepts, and knowledge that need not be tied to a personally experienced event.

## 2. Definition
Semantic memory is long-term memory for general knowledge, meanings, facts, concepts, and relationships that are not necessarily remembered as belonging to one particular episode.

## 3. Core Understanding
Semantic knowledge includes vocabulary, factual knowledge, category knowledge, and conceptual relationships. It can be acquired from many episodes and later used without recalling the original learning event.

### Mechanism
Repeated experiences can abstract common information across episodes, allowing knowledge to become less dependent on the specific context in which it was acquired.

### Boundary conditions
Semantic and episodic memory interact. A factual belief may originate from an episode yet later be retained without access to its source.

## 4. Relationship to This Chapter
Semantic memory is a major branch of declarative long-term memory alongside episodic memory.

## 5. Boundaries
### Owns

### Defers

## 3. Core Understanding
Priming can occur through perceptual, conceptual, semantic, or response-related pathways. It is often measured as faster, more accurate, or more likely responding after prior exposure.

Prior activation or learning can change accessibility or processing efficiency for related information. Different forms of priming need not share one mechanism.

### Boundary conditions

### Owns

## 3. Core Understanding
Conditioned responses can persist after learning and can be expressed without deliberate recollection of the acquisition episode. The underlying association can also be modified by extinction, context change, and new learning.

### Boundary conditions

Prospective memory combines future intention maintenance with detection of the situation in which the intended action should occur.

Flashbulb memories often feel exceptionally vivid and detailed, but vividness and confidence do not guarantee accuracy.

## 1.8.34 Recognition

## 1. Purpose
Explain memory expressed when previously encountered information is identified as familiar or remembered.

## 2. Definition
Recognition is retrieval in which a person identifies a current stimulus or information as previously encountered.

## 3. Core Understanding
Recognition supplies the present stimulus itself as a retrieval cue, making it generally easier than free recall. Recognition can nevertheless produce errors when familiarity is mistaken for prior occurrence.

### Mechanism
Recognition can involve familiarity, recollection, or both. Familiarity provides a sense that something has been encountered before, whereas recollection retrieves contextual details about the prior encounter.

### Boundary conditions
Repeated or similar information can produce false recognition. Confidence can also be influenced by fluency, familiarity, and decision criteria.

## 4. Relationship to This Chapter
Recognition is a major retrieval format and connects memory access with familiarity and recollection.

## 5. Boundaries
### Owns
Owns identification of previously encountered information during memory testing or use.

### Defers
Recall concerns retrieval without the target being presented; familiarity and recollection specialize recognition processes.

## 6. Key Principles
- Recognition benefits from an external retrieval cue.
- Familiarity and recollection can contribute differently.
- Recognition can be confidently wrong.

## 1.8.35 Recall

## 1. Purpose
Explain retrieval of information without the target being fully supplied as a recognition cue.

## 2. Definition
Recall is retrieval of previously learned information through internally generated or partial cues rather than direct identification of the target among presented alternatives.

## 3. Core Understanding
Recall places greater demands on retrieval search and cue generation than recognition. Free recall, cued recall, and serial recall differ in how much support the environment provides.

### Mechanism
Effective recall depends on retrieval cues, organization, context, and competition among memories. The absence of a recalled item does not necessarily establish that the memory is absent.

### Boundary conditions
Recall can be impaired by interference, poor cue availability, and changes between learning and testing.

### Measurement
Recall performance should be interpreted relative to the task format because different forms provide different retrieval support.

## 4. Relationship to This Chapter
Recall is the principal retrieval format that contrasts with recognition.

## 5. Boundaries
### Owns
Owns retrieval of information without direct recognition alternatives.

### Defers
Retrieval owns the broader process; recognition, familiarity, and recollection specialize other retrieval forms.

## 6. Key Principles
- Recall requires greater self-generated retrieval than recognition.
- Retrieval cues strongly affect recall.
- Failure to recall is not proof of complete memory loss.

Residual representations, associations, procedures, or strategies can facilitate renewed acquisition.

Savings can provide evidence of memory that direct recall or recognition may underestimate.

## 1.8.37 Context-dependent memory

## 1. Purpose
Explain how external environmental context can influence retrieval.

## 2. Definition
Context-dependent memory is improved or altered remembering produced by overlap between the environmental context at encoding and retrieval.

## 3. Core Understanding
Environmental features can become associated with learned information and later serve as retrieval cues.

### Mechanism
Returning to a similar physical or situational environment can reinstate cues that were present during encoding, increasing access to associated information.

### Boundary conditions
Context effects are not universal or equally strong across tasks. Distinctive contextual information and strong internal or semantic cues can alter the magnitude of the effect.

### Evidence status
Context-dependent effects are supported experimentally, but popular claims that simply returning to a location reliably restores forgotten memories overstate the evidence.

## 4. Relationship to This Chapter

## 5. Boundaries
### Owns

### Defers

## 1.8.38 State-dependent memory

Explain how internal physiological or psychological state can influence retrieval when it overlaps with the state present during encoding.

## 2. Definition
State-dependent memory is a memory effect in which similarity between internal states at encoding and retrieval can influence accessibility of learned information.

## 3. Core Understanding
Internal states can become associated with information during learning and later function as retrieval cues. States may include mood, arousal, or physiological conditions.

### Mechanism
State overlap can reinstate internal cues associated with the original learning episode.

### Evidence status

## 1.8.39 Retrieval practice

## 1. Purpose
Explain why actively retrieving information can improve later memory.

## 2. Definition
Retrieval practice is repeated intentional retrieval of learned information as a method of strengthening later access.

## 3. Core Understanding
Testing oneself can improve subsequent retention more effectively than passive restudy under many conditions. Retrieval requires reconstruction of the target and can strengthen access pathways.

### Mechanism
Successful retrieval can increase later accessibility and improve discrimination among competing information. Feedback can correct errors and further strengthen accurate memory.

### Boundary conditions
Benefits depend on retrieval difficulty, feedback, spacing, material, and learner knowledge. Repeated retrieval of an incorrect answer can reinforce error.

### Evidence status
The testing effect is robust across many laboratory and educational settings, although optimal practice schedules depend on task and material.

## 4. Relationship to This Chapter
Retrieval practice demonstrates that retrieval is not merely an output of memory; it can also modify later memory.

## 5. Boundaries
### Owns
Owns repeated retrieval as a memory-strengthening process.

### Defers
Testing effect names the broader empirical effect; spacing effect concerns distribution across time.

## 6. Key Principles
- Retrieval can strengthen later memory.
- Effortful successful retrieval can be especially useful.
- Feedback matters when retrieval can produce errors.

## 1.8.40 Spacing effect

## 1. Purpose
Explain why distributing learning episodes over time often improves later retention compared with massing them together.

## 2. Definition
The spacing effect is the finding that learning distributed across separated time intervals often produces better long-term retention than equivalent learning concentrated in a single period.

## 3. Core Understanding
Spacing creates opportunities for partial forgetting and renewed retrieval, producing richer and more varied retrieval conditions.

### Mechanism
Repeated encounters separated by time can increase retrieval effort, vary contextual cues, and encourage reconstruction of the material rather than simple short-term repetition.

### Boundary conditions
The optimal spacing interval depends on the desired retention interval, material, learner, and task. Spacing does not mean that every delay is equally beneficial.

### Evidence status
Spacing effects are among the more robust findings in learning and memory research.

## 4. Relationship to This Chapter
Spacing shows how temporal organization of encoding and retrieval affects long-term memory.

## 5. Boundaries
### Owns
Owns the temporal distribution principle for repeated learning.

### Defers
Retrieval practice owns active retrieval; testing effect owns the broader benefit of retrieval-based learning.

## 6. Key Principles
- Distributed practice often improves durable retention.
- Optimal spacing depends on the desired retention interval.
- Time between learning episodes can increase useful retrieval effort.

## 3. Core Understanding

### Boundary conditions

## 1.8.42 Forgetting

## 1. Purpose
Explain reduced accessibility or loss of previously acquired information over time or through interference.

## 2. Definition
Forgetting is reduced ability to retrieve or express previously learned information.

## 3. Core Understanding
Forgetting has multiple possible causes. Information may become less accessible, be blocked by competing memories, lack effective retrieval cues, or undergo changes in representation.

### Mechanisms
Decay, interference, retrieval failure, motivated or directed forgetting, and contextual change can contribute under different conditions. Forgetting therefore cannot be attributed to time alone.

### Boundary conditions
A memory that cannot be recalled may still influence performance or be relearned rapidly. Forgetting is consequently not identical to complete erasure.

### Evidence status
Forgetting is a robust phenomenon, while the relative contribution of specific mechanisms varies by memory type and experimental conditions.

## 4. Relationship to This Chapter
Forgetting organizes the chapter's processes that reduce accessibility of previously learned information.

## 5. Boundaries
### Owns
Owns the general phenomenon of reduced memory accessibility.

### Defers
Decay, interference, retrieval failure, and specialized forgetting effects have dedicated Topics.

## 6. Key Principles
- Forgetting can arise from multiple mechanisms.
- Inaccessibility does not necessarily mean erasure.
- Memory strength and retrieval accessibility are not identical.

## 1.8.43 Decay

## 1. Purpose
Explain the possibility that memory accessibility decreases as time passes.

## 2. Definition
Decay is a proposed reduction in the accessibility or strength of a memory representation associated with the passage of time.

## 3. Core Understanding
Time can matter for memory, but pure time-based decay is difficult to isolate because delay usually allows other experiences and interference to occur.

### Mechanism
Theories differ on whether representations weaken intrinsically over time or whether apparent decay largely reflects interference, contextual change, and retrieval competition.

### Evidence status
Short-term forgetting can occur rapidly, but demonstrating time-driven loss independent of interference is difficult. Modern memory science therefore treats decay as one possible process rather than a complete explanation of forgetting.

### Boundary conditions
Some memories remain accessible for very long periods, and spaced retrieval can preserve access despite long delays.

## 4. Relationship to This Chapter
Decay represents the time-based account of forgetting and contrasts with interference-based explanations.

## 5. Boundaries
### Owns
Owns the hypothesis that memory accessibility can decline with time.

### Defers
Interference owns competition from other learning; retrieval failure owns cue-access problems.

## 6. Key Principles
- Time and forgetting are related but not identical.
- Pure decay is difficult to separate from interference.
- Long delays do not guarantee complete memory loss.

## 1.8.44 Interference

## 1. Purpose
Explain forgetting caused by competition among memories or learning episodes.

## 2. Definition
Interference is reduced memory performance caused by competing information that disrupts encoding, storage, retrieval, or expression of a target memory.

## 3. Core Understanding
Interference is strongest when memories overlap in content, cues, or response requirements. Earlier and later learning can compete in different directions.

### Types
Proactive interference occurs when older information disrupts newer information; retroactive interference occurs when newer information disrupts older information.

### Mechanism
Competing representations can activate overlapping retrieval pathways, making the target harder to select or discriminate.

### Boundary conditions
Similarity, temporal proximity, cue overlap, and task structure influence interference.

## 4. Relationship to This Chapter
Interference is the broad competition-based mechanism underlying several specialized forgetting effects.

## 5. Boundaries
### Owns
Owns competition among memories as a general forgetting mechanism.

### Defers
Proactive and retroactive interference specify direction; retrieval-induced forgetting concerns selective retrieval effects.

## 6. Key Principles
- Similar memories compete more strongly.
- Interference can operate in both temporal directions.
- Forgetting can reflect competition rather than erasure.

## 1.8.45 Proactive interference

## 1. Purpose
Explain how earlier learning can interfere with later learning or retrieval.

## 2. Definition
Proactive interference occurs when previously learned information disrupts acquisition, retrieval, or performance involving newer information.

## 3. Core Understanding
Older associations can remain active when a person attempts to learn or retrieve newer material, particularly when the materials are similar.

### Mechanism
Prior information competes for overlapping cues or responses. The person may retrieve an older answer because it has stronger or more accessible associations with the current cue.

### Boundary conditions
Interference increases with similarity and cue overlap but can be reduced by distinctive encoding, contextual separation, and practice with the new information.

### Example
A previously used password pattern can make it harder to retrieve a newly changed password.

## 4. Relationship to This Chapter
Proactive interference is the forward direction of interference from earlier learning to later memory.

## 5. Boundaries
### Owns
Owns interference produced by prior learning.

### Defers
Retroactive interference concerns later learning disrupting earlier memory; interference is the broader mechanism.

## 6. Key Principles
- Older learning can interfere with newer learning.
- Similarity increases competition.
- Distinctive new encoding can reduce interference.

## 1.8.46 Retroactive interference

## 1. Purpose
Explain how newer learning can interfere with earlier memory.

## 2. Definition
Retroactive interference occurs when information learned later disrupts retrieval or expression of previously learned information.

## 3. Core Understanding
New learning can compete with earlier memory when the two sets of information share cues or response structures.

### Mechanism
Later associations can become strongly linked to retrieval cues that previously activated older information. When the cue is encountered, the newer response may dominate or create competition.

### Boundary conditions
Interference depends on similarity, amount of new learning, temporal proximity, and cue structure. New learning does not necessarily erase the older memory.

### Measurement
Improved relearning can sometimes reveal residual older learning even when direct recall is impaired.

## 4. Relationship to This Chapter
Retroactive interference is the backward direction of interference from later learning to earlier memory.

## 5. Boundaries
### Owns
Owns interference produced by subsequent learning.

### Defers
Proactive interference concerns older learning affecting newer memory.

## 6. Key Principles
- New learning can impair access to older information.
- Similarity increases retroactive competition.
- Reduced retrieval does not prove erasure.

## 1.8.47 Retrieval failure

## 1. Purpose
Explain cases in which stored information is not accessible with the cues available at the moment.

## 2. Definition
Retrieval failure is inability to access previously learned information when current retrieval cues are insufficient, inappropriate, or overshadowed by competing information.

## 3. Core Understanding
A person can know something yet fail to retrieve it at a particular moment. The information may become accessible when a better cue, context, or state is provided.

### Mechanism
Retrieval is cue-dependent. If the current cue does not effectively activate the relevant memory or if competing memories dominate, access can fail.

### Boundary conditions
Repeated failure does not prove permanent loss. Conversely, later successful retrieval does not establish that the memory was continuously intact in an unchanged form.

### Related phenomena
Tip-of-the-tongue states provide a particularly vivid example of temporary retrieval difficulty.

## 4. Relationship to This Chapter
Retrieval failure explains why forgetting cannot be equated simply with disappearance of stored information.

## 5. Boundaries
### Owns
Owns inaccessible memory caused by inadequate or ineffective retrieval conditions.

### Defers
Retrieval cues and encoding specificity explain cue mechanisms; decay and interference provide alternative forgetting mechanisms.

## 6. Key Principles
- Accessibility is not identical to existence of memory.
- Better cues can sometimes restore access.
- Retrieval failure has multiple possible causes.

## 1.8.48 Tip-of-the-tongue state

## 1. Purpose
Explain the temporary experience of being unable to retrieve known information while feeling that retrieval is imminent.

## 2. Definition
A tip-of-the-tongue state is a temporary retrieval state in which a person cannot produce a target item but has a strong sense that it is known and may retrieve it soon.

## 3. Core Understanding
The state is especially common for names and low-frequency words. People may have partial information, such as initial sounds, syllable count, or related meaning, without accessing the complete target.

### Mechanism
Partial activation of the target can occur without sufficient activation for full retrieval. Competing candidates can further delay access.

### Boundary conditions
The subjective feeling of knowing is informative but not infallible. A person can sometimes feel close to retrieval and still fail to produce the correct answer.

### Measurement
Researchers can compare later successful retrieval, partial phonological information, and cue effects to distinguish retrieval difficulty from complete absence of knowledge.

## 4. Relationship to This Chapter
This Topic is a specific subjective and behavioral manifestation of retrieval failure.

## 5. Boundaries
### Owns
Owns temporary, subjectively experienced word-retrieval blockage.

### Defers
Retrieval failure owns the broader mechanism; metamemory owns judgments about one's own memory.

## 6. Key Principles
- Partial activation can occur without complete retrieval.
- Tip-of-the-tongue states are temporary retrieval difficulties.
- Subjective confidence does not guarantee correct retrieval.

## 1.8.49 Directed forgetting

## 1. Purpose
Explain memory effects produced when people are instructed to remember some information and intentionally disregard other information.

## 2. Definition
Directed forgetting is reduced later memory for information that people were instructed to forget compared with information they were instructed to remember, under appropriate experimental conditions.

## 3. Core Understanding
Instructions to forget can alter subsequent encoding, rehearsal, retrieval strategy, or accessibility. Different experimental paradigms produce somewhat different mechanisms.

### Mechanism
In item-method procedures, an instruction can change the priority given to individual items. In list-method procedures, an instruction to forget a preceding list can alter the mental context or retrieval strategy applied to that material.

### Boundary conditions
Directed forgetting is not equivalent to deliberate erasure. Some forgotten information can remain measurable through indirect tests or can be recovered under changed conditions.

### Evidence status
The phenomenon is robust, but its mechanisms differ by paradigm.

## 4. Relationship to This Chapter
Directed forgetting is a specialized form of intentional memory control and forgetting.

## 5. Boundaries
### Owns
Owns experimentally induced forgetting following intentional remember/forget instructions.

### Defers
Memory control addresses broader regulation; retrieval-induced forgetting concerns selective retrieval rather than explicit forget instructions.

## 6. Key Principles
- Instructions can alter later memory.
- Forgetting instructions do not necessarily erase information.
- Different directed-forgetting paradigms rely on different mechanisms.

---

## 1.8.50 Retrieval-induced forgetting

## 1. Purpose
Explain how retrieving some information can reduce later accessibility of related information.

## 2. Definition
Retrieval-induced forgetting is reduced later retrieval of information related to material that was selectively retrieved earlier.

## 3. Core Understanding
Selective retrieval can improve access to practiced items while making related unpracticed items harder to retrieve later.

### Mechanism
Competing accounts emphasize inhibitory control, retrieval competition, and changes in contextual or associative accessibility. The effect depends on the structure of the materials and retrieval procedure.

### Boundary conditions
Not every retrieval task produces forgetting of related information, and the effect should not be interpreted as intentional deletion.

### Evidence status
The phenomenon has substantial experimental support, while the exact mechanism remains debated.

## 4. Relationship to This Chapter
This Topic shows that retrieval can produce both strengthening of practiced information and reduced accessibility of competing information.

## 5. Boundaries
### Owns
Owns selective-retrieval effects on later accessibility of related information.

### Defers
Retrieval practice owns the general strengthening effect; interference owns the broader competition mechanism.

## 6. Key Principles
- Selective retrieval can change later memory for related material.
- Strengthening one memory can have consequences for competitors.
- Mechanisms of retrieval-induced forgetting remain debated.

---

## 1.8.51 Serial-position effect

## 1. Purpose
Explain why an item's position in a sequence influences its likelihood of later recall.

## 2. Definition
The serial-position effect is the tendency for memory performance to vary systematically according to an item's position within a presented sequence.

## 3. Core Understanding
Items near the beginning and end of a list are often remembered better than middle items, producing the characteristic serial-position curve.

### Mechanism
Early items can receive more rehearsal and transfer opportunities, while the most recent items may remain accessible in short-term or working memory at immediate test.

### Boundary conditions
The size and shape of the effect depend on list length, presentation rate, delay, distraction, and whether recall is immediate or delayed.

### Related concepts
Primacy and recency effects are the two major components of the serial-position pattern.

## 4. Relationship to This Chapter
This Topic organizes positional effects in memory and provides the parent phenomenon for primacy and recency.

## 5. Boundaries
### Owns
Owns the overall relationship between sequence position and memory performance.

### Defers
Primacy and recency specialize the early- and late-position effects.

## 6. Key Principles
- Memory varies systematically with position in a sequence.
- Early and late items can receive different advantages.
- Experimental conditions determine the strength of each component.

---

## 1.8.52 Primacy effect

## 1. Purpose
Explain enhanced memory for information presented early in a sequence.

## 2. Definition
The primacy effect is improved memory for items near the beginning of a sequence relative to many middle items.

## 3. Core Understanding
Early items often receive more opportunities for rehearsal and integration with long-term memory, especially when presentation is sufficiently slow.

### Mechanism
Additional rehearsal can increase encoding and long-term retention of early items. Distinctive initial positions can also influence organization and retrieval.

### Boundary conditions
The effect can change with presentation rate, list length, rehearsal opportunity, and test delay. It is not simply a permanent advantage attached to being first.

## 4. Relationship to This Chapter
Primacy is the early-position component of the serial-position effect.

## 5. Boundaries
### Owns
Owns enhanced memory associated with early serial positions.

### Defers
Serial-position effect owns the overall pattern; recency concerns late-position advantage.

## 6. Key Principles
- Early items often receive more rehearsal.
- Primacy depends on task conditions.
- It is one component of the serial-position curve.

---

## 1.8.53 Recency effect

## 1. Purpose
Explain enhanced memory for information presented most recently.

## 2. Definition
The recency effect is improved memory for items near the end of a sequence, particularly under immediate retrieval conditions.

## 3. Core Understanding
Recent items can remain relatively accessible because they have received little intervening processing and may still be represented in temporary memory.

### Mechanism
Immediate recall can benefit from residual accessibility of recently presented information. Delays, distraction, and competing tasks can reduce this advantage.

### Boundary conditions
Recency is highly sensitive to the interval and activity between presentation and test, making it distinct from the more durable mechanisms underlying primacy.

## 4. Relationship to This Chapter
Recency is the late-position component of the serial-position effect.

## 5. Boundaries
### Owns
Owns enhanced memory for recent sequence positions.

### Defers
Serial-position effect owns the complete position curve; short-term and working memory own broader temporary-retention mechanisms.

## 6. Key Principles
- Recent information can have privileged immediate accessibility.
- Intervening activity can reduce recency.
- Recency is strongly task- and delay-dependent.

---

## 1.8.54 Memory distortion

## 1. Purpose
Explain systematic changes between experienced information and later remembered information.

## 2. Definition
Memory distortion is a systematic alteration, omission, addition, or transformation of remembered information relative to the original experience or source.

## 3. Core Understanding
Memory is reconstructive. Distortions can arise during encoding, consolidation, retrieval, post-event learning, source attribution, and reconstruction.

### Mechanisms
Schemas, expectations, misinformation, suggestibility, source confusion, and repeated retrieval can influence what is later remembered.

### Boundary conditions
Distortion does not mean memory is generally unreliable. Much memory is accurate enough for ordinary functioning, but accuracy varies with material, delay, interference, and retrieval conditions.

### Evidence status
Memory distortion is extensively documented in controlled experiments and applied research.

## 4. Relationship to This Chapter
This Topic begins the memory-error architecture by distinguishing reconstruction from exact replay.

## 5. Boundaries
### Owns
Owns systematic alteration of remembered information.

### Defers
False memory, misinformation, source monitoring, and reconstruction specify important mechanisms or manifestations.

## 6. Key Principles
- Remembering is reconstructive.
- Distortion can occur without deliberate lying.
- Accuracy varies by conditions and memory type.

---

## 1.8.55 False memory

## 1. Purpose
Explain memories that are experienced as genuine but contain information that did not occur as remembered.

## 2. Definition
False memory is a memory representation experienced as remembering but containing information that is inaccurate or did not occur in the relevant form.

## 3. Core Understanding
False memories can range from small details embedded in an otherwise accurate event to memories of events that did not occur. They can arise without conscious intention to deceive.

### Mechanisms
Source confusion, suggestion, associative activation, imagination, schemas, and repeated reconstruction can contribute.

### Boundary conditions
False-memory susceptibility varies with material, procedure, individual differences, and the strength of competing information. Confidence can increase without a corresponding increase in accuracy.

### Evidence status
False-memory phenomena are well established experimentally, but the mechanisms and magnitude of effects vary across paradigms.

## 4. Relationship to This Chapter
False memory is a major outcome of reconstructive memory and connects distortion with source monitoring and suggestibility.

## 5. Boundaries
### Owns
Owns inaccurate memories experienced as genuine remembering.

### Defers
Misinformation and suggestibility describe important causes; memory confidence and accuracy distinguish subjective certainty from objective correspondence.

## 6. Key Principles
- False memories can feel subjectively real.
- Confidence is not a direct measure of accuracy.
- Multiple reconstructive mechanisms can produce false memory.

---

## 1.8.56 Misinformation effect

## 1. Purpose
Explain how later misleading information can alter memory for an earlier event.

## 2. Definition
The misinformation effect is reduced or altered memory accuracy for an original event after exposure to misleading information about that event.

## 3. Core Understanding
Post-event information can influence later reports through memory updating, source confusion, retrieval competition, or other reconstructive processes.

### Mechanism
A later misleading detail can become associated with the event representation or can be confused with the original source. The effect is especially important when original and misleading information overlap.

### Boundary conditions
People do not accept every suggestion equally. Distinctive original details, source monitoring, warnings, and strong memory can sometimes reduce susceptibility.

### Evidence status
The effect is strongly established experimentally and has important implications for eyewitness memory.

## 4. Relationship to This Chapter
The misinformation effect is a specific form of memory distortion caused by post-event information.

## 5. Boundaries
### Owns
Owns alteration of memory following exposure to misleading post-event information.

### Defers
Eyewitness memory applies these principles to witness situations; suggestibility is the broader susceptibility construct.

## 6. Key Principles
- Later information can alter memory for earlier events.
- Source confusion is one important mechanism.
- Warnings and strong original encoding can reduce, but not necessarily eliminate, effects.

---

## 1.8.57 Source monitoring

## 1. Purpose
Explain how people determine where a remembered piece of information came from.

## 2. Definition
Source monitoring is the process of evaluating the origin or source of remembered information.

## 3. Core Understanding
Remembering content and remembering its source are separable. A person may remember a fact or detail while misattributing whether it was seen, heard, imagined, inferred, or learned from another person.

### Mechanism
Source judgments rely on qualitative characteristics of memories, contextual information, familiarity, and reasoning. More vivid or perceptually rich information can sometimes be mistaken for directly experienced information.

### Boundary conditions
Source monitoring is fallible, especially when different sources contain similar content or when delay and suggestion weaken source distinctions.

## 4. Relationship to This Chapter
Source monitoring provides a central mechanism for understanding false memory and misinformation.

## 5. Boundaries
### Owns
Owns judgments about the origin of remembered information.

### Defers
Source memory concerns memory for source information; suggestibility and misinformation are important contexts in which source errors occur.

## 6. Key Principles
- Remembering content does not guarantee remembering its source.
- Source judgments are inferential and fallible.
- Source confusion can produce genuine-feeling memory errors.

---

## 1.8.58 Source memory

## 1. Purpose
Explain memory for contextual information about where, when, or from whom information was learned.

## 2. Definition
Source memory is memory for the origin or contextual circumstances associated with previously learned information.

## 3. Core Understanding
Source memory can include who provided information, where it was encountered, when it occurred, or whether it was perceived, imagined, inferred, or communicated.

### Mechanism
Source information is encoded alongside content to varying degrees. Later retrieval can recover content while failing to recover its source, creating source-monitoring errors.

### Boundary conditions
Source memory often declines faster than familiarity with content. Similar sources and repeated exposure can increase confusion.

### Related concepts
Source monitoring is the broader evaluative process; source memory is the remembered source information itself.

## 4. Relationship to This Chapter
Source memory provides the stored contextual information needed for accurate attribution of remembered content.

## 5. Boundaries
### Owns
Owns retained information about the origin and context of memories.

### Defers
Source monitoring owns source-evaluation processes; misinformation and suggestibility own important distortion pathways.

## 6. Key Principles
- Content and source can be remembered separately.
- Source information is often vulnerable to forgetting.
- Source errors can transform accurate content into misleading memories.

---

## 1.8.59 Memory reconstruction

## 1. Purpose
Explain how remembering involves rebuilding an event or knowledge representation from stored information and current cues.

## 2. Definition
Memory reconstruction is the process of generating a remembered representation by combining retained information with contextual knowledge, schemas, expectations, and current retrieval conditions.

## 3. Core Understanding
Remembering is neither pure replay nor unconstrained invention. Existing traces constrain reconstruction, while current knowledge and context influence which details are selected and how gaps are filled.

### Mechanism
Retrieval activates partial information, which is integrated with schemas, semantic knowledge, contextual cues, and current goals. Repeated reconstruction can therefore change later reports.

### Boundary conditions
Reconstruction can improve usefulness by filling predictable gaps, but it can also introduce inaccuracies.

### Evidence status
Reconstructive memory is supported by extensive experimental evidence, although the exact balance between stored traces and reconstructive processes differs across memory tasks.

## 4. Relationship to This Chapter
This Topic provides the general process underlying many memory errors and explains why accurate and distorted remembering can coexist.

## 5. Boundaries
### Owns
Owns the reconstructive process of generating remembered representations.

### Defers
Memory distortion describes inaccurate outcomes; source monitoring and misinformation describe specific mechanisms.

## 6. Key Principles
- Remembering combines retained information with current knowledge.
- Reconstruction is constrained, not arbitrary.
- The reconstructive process can produce both useful and inaccurate memory.

---

## 1.8.60 Suggestibility

## 1. Purpose
Explain how memory reports can be influenced by suggestions from other people, questions, expectations, or contextual information.

## 2. Definition
Suggestibility is the tendency for memory reports or memory representations to be altered by information introduced through suggestion.

## 3. Core Understanding
Suggestion can influence what a person reports remembering without implying intentional fabrication. Effects vary with source monitoring, confidence, social context, prior knowledge, and the strength of original memory.

### Mechanism
Suggested information can become integrated into the memory representation, misattributed to the original event, or used during reconstruction.

### Boundary conditions
Suggestibility is not uniform across individuals or situations. Strong original encoding, distinctive details, warnings, and careful interviewing can reduce some effects.

### Evidence status
Suggestibility is well documented, especially in research on eyewitness and developmental memory.

## 4. Relationship to This Chapter
Suggestibility is a major pathway through which social and post-event information can influence memory.

## 5. Boundaries
### Owns
Owns susceptibility of memory to externally introduced suggestions.

### Defers
Misinformation effect is a specific experimental form; source monitoring explains attribution processes.

## 6. Key Principles
- Suggestion can alter memory reports and sometimes memory representations.
- Susceptibility varies by person, material, and context.
- Suggestibility is not equivalent to intentional deception.

## 1.8.61 Eyewitness memory

## 1. Purpose
Explain memory for witnessed events in situations where accuracy can have important consequences.

## 2. Definition
Eyewitness memory is memory for observed events, people, actions, and circumstances reported by a witness.

## 3. Core Understanding
Eyewitness memory is subject to ordinary encoding, retrieval, reconstruction, source-monitoring, and social-influence processes. Stress, attention, weapon focus, delay, questioning, post-event information, and identification procedures can affect performance, but effects are context-dependent.

### Mechanism
Witnesses encode only selected aspects of an event. Later information and retrieval conditions can alter reports or confidence. Identification procedures also create decision and memory demands that must be separated analytically.

### Boundary conditions
Confidence and accuracy can be related under some carefully controlled conditions but are not universally interchangeable.

### Evidence status
Eyewitness-memory research is extensive and has demonstrated both reliable vulnerabilities and conditions under which memory can be comparatively accurate.

## 4. Relationship to This Chapter
Eyewitness memory is an applied manifestation of the chapter's general memory and error mechanisms.

## 5. Boundaries
### Owns
Owns memory for witnessed events and their characteristic evidential conditions.

### Defers
General memory distortion, misinformation, and source monitoring own universal mechanisms; legal decision-making belongs outside System 1's universal memory ontology.

## 6. Key Principles
- Eyewitness memory is neither uniformly reliable nor uniformly unreliable.
- Questioning and post-event information can matter.
- Confidence must not be treated as a simple substitute for accuracy.

## 1.8.62 Familiarity

## 1. Purpose
Explain the feeling that something has been encountered before without necessarily retrieving contextual details.

## 2. Definition
Familiarity is a relatively context-poor sense that a stimulus, person, fact, or event has been encountered previously.

## 3. Core Understanding
Familiarity can contribute to recognition without full recollection of the original episode. It is often experienced as a graded feeling rather than a detailed memory.

### Mechanism
Repeated exposure, processing fluency, and stored associations can increase familiarity. Because these signals are not inherently source-specific, they can sometimes produce false recognition.

### Boundary conditions
Familiarity and recollection can coexist, and their relative contribution depends on task, delay, and stimulus properties.

### Evidence status
Dual-process approaches distinguish familiarity and recollection, although the degree to which they reflect separable mechanisms remains debated.

## 4. Relationship to This Chapter
Familiarity is one major component of recognition and helps explain why recognition can occur without detailed episodic retrieval.

## 5. Boundaries
### Owns
Owns the context-poor sense of prior encounter.

### Defers
Recollection owns contextual retrieval; recognition is the broader retrieval format.

## 6. Key Principles
- Familiarity can support recognition without detailed recollection.
- Familiarity is not inherently source-specific.
- Familiarity can contribute to false recognition.

---

## 1.8.63 Recollection

## 1. Purpose
Explain retrieval that includes contextual information about a prior experience.

## 2. Definition
Recollection is retrieval of a prior experience together with contextual or episodic information about that experience.

## 3. Core Understanding
Recollection is more information-rich than a simple feeling of familiarity. It can include where, when, how, and under what circumstances an item was encountered.

### Mechanism
Recollection depends on retrieving linked contextual details and binding them to the target information. It is therefore vulnerable to source errors and reconstruction.

### Boundary conditions
Recollection and familiarity can contribute simultaneously to recognition. A strong feeling of recollection is not a guarantee that every retrieved detail is accurate.

### Evidence status
The distinction is influential in recognition-memory research, though theoretical accounts differ on whether familiarity and recollection are fully separable processes.

## 4. Relationship to This Chapter
Recollection is the context-rich counterpart to familiarity within recognition memory.

## 5. Boundaries
### Owns
Owns context-rich retrieval of prior experiences.

### Defers
Familiarity owns context-poor recognition; episodic memory owns the broader event-memory system.

## 6. Key Principles
- Recollection includes contextual information.
- Recollection can be vivid yet reconstructive.
- Familiarity and recollection can operate together.

---

## 1.8.64 Memory confidence

## 1. Purpose
Explain how certain a person feels about the correctness of a memory.

## 2. Definition
Memory confidence is a person's subjective degree of certainty that a remembered detail, event, or answer is accurate.

## 3. Core Understanding
Confidence is a metacognitive judgment, not a direct readout of objective memory accuracy. It can be influenced by fluency, vividness, familiarity, social feedback, retrieval ease, and decision context.

### Mechanism
People infer memory reliability from available internal and external cues. Some cues are diagnostic of accuracy, while others increase confidence without increasing correspondence to the original event.

### Boundary conditions
Confidence–accuracy relationships vary with task and retrieval conditions. Careful encoding and controlled retrieval procedures can improve calibration.

## 4. Relationship to This Chapter
Memory confidence is central to understanding why subjective certainty and objective accuracy must be evaluated separately.

## 5. Boundaries
### Owns
Owns subjective certainty about memory correctness.

### Defers
Memory accuracy owns correspondence with the original information; metamemory owns broader knowledge and monitoring of memory.

## 6. Key Principles
- Confidence is not identical to accuracy.
- Confidence is influenced by multiple cues.
- Calibration matters when memory judgments have consequences.

---

## 1.8.65 Memory accuracy

## 1. Purpose
Explain correspondence between remembered information and the relevant original information or event.

## 2. Definition
Memory accuracy is the degree to which a memory report or representation corresponds correctly to the information or event being remembered.

## 3. Core Understanding
Accuracy is evaluated against an appropriate criterion, such as a documented event, known answer, or verified source. It differs from confidence, vividness, and completeness.

### Measurement
Accuracy can involve item correctness, detail accuracy, source accuracy, temporal accuracy, or event-level correspondence. A memory can be accurate in central content while inaccurate in peripheral details.

### Boundary conditions
The appropriate standard depends on the memory task. Accuracy can decline with delay, interference, suggestion, and reconstruction, but effects vary across conditions.

### Evidence status
Accuracy is an empirical property to be measured rather than inferred from subjective experience alone.

## 4. Relationship to This Chapter
Memory accuracy provides the objective side of the distinction between what is remembered and how certain the person feels.

## 5. Boundaries
### Owns
Owns correspondence between memory and the relevant target information.

### Defers
Confidence owns subjective certainty; memory monitoring concerns judgments and evaluation processes.

## 6. Key Principles
- Accuracy requires an external or independently justified criterion.
- Confidence and accuracy are distinct variables.
- Memory can be partly accurate and partly distorted.

## 1.8.66 Metamemory

## 1. Purpose
Explain people's knowledge and beliefs about their own memory and memory processes.

## 2. Definition
Metamemory is knowledge, beliefs, judgments, and monitoring concerning one's own memory abilities and memory states.

## 3. Core Understanding
Metamemory includes knowing how memory works, predicting whether information will be remembered, judging whether a response is correct, and selecting strategies to improve remembering.

### Components
Metamemory includes monitoring and control. Monitoring concerns judgments about memory; control concerns decisions such as what to study, when to retrieve, or whether more effort is needed.

### Boundary conditions
Metamemory judgments can be accurate, but they can also be systematically biased by familiarity, fluency, confidence, and other cues.

### Consequences
Effective metamemory can improve study decisions and retrieval strategies, while poor calibration can lead to premature stopping or misplaced confidence.

## 4. Relationship to This Chapter
Metamemory provides the self-monitoring layer of the memory system and organizes confidence, monitoring, and control.

## 5. Boundaries
### Owns
Owns knowledge and judgments about one's own memory.

### Defers
Memory confidence specializes subjective certainty; memory monitoring and control specialize its component processes.

## 6. Key Principles
- Metamemory concerns knowledge and judgments about memory.
- Monitoring and control are related but distinct.
- Metamemory can itself be inaccurate.

## 1.8.67 Memory monitoring

## 1. Purpose
Explain processes used to evaluate the current status or reliability of one's memory.

## 2. Definition
Memory monitoring is the process of evaluating whether information has been learned, remembered, recognized, or retrieved correctly.

## 3. Core Understanding
Monitoring includes judgments such as feeling that an answer is known, evaluating confidence, deciding whether a source is remembered correctly, and assessing whether additional study or retrieval is needed.

### Mechanism
Monitoring relies on cues such as retrieval fluency, familiarity, vividness, partial information, and contextual evidence. Some cues are diagnostic; others can produce systematic errors.

### Boundary conditions
Monitoring accuracy varies with task demands, cue quality, feedback, and prior knowledge.

## 4. Relationship to This Chapter
Memory monitoring is the evaluative process underlying many metamemory judgments.

## 5. Boundaries
### Owns
Owns evaluation of current memory states and performance.

### Defers
Metamemory is the broader domain; memory confidence is one output of monitoring; memory control concerns actions based on monitoring.

## 6. Key Principles
- Monitoring evaluates memory rather than storing it.
- Monitoring depends on imperfect cues.
- Better calibration requires better diagnostic information.

## 1.8.68 Memory control

## 1. Purpose
Explain deliberate regulation of memory acquisition, retention, retrieval, and use.

## 2. Definition
Memory control is the set of intentional processes through which people regulate what they encode, practice, retrieve, maintain, suppress, or use from memory.

## 3. Core Understanding
People make decisions about what to study, what to retrieve, when to stop searching memory, and which strategies to use. Control therefore connects memory with goals and executive regulation.

### Mechanism
Monitoring provides information about the current memory state, while control uses that information to select strategies or allocate effort.

### Forms
Examples include choosing to rehearse, spacing study, retrieving difficult information, using external cues, or intentionally changing retrieval priorities.

### Boundary conditions
Control is limited by available knowledge, attention, time, motivation, and the accuracy of monitoring.

## 4. Relationship to This Chapter
Memory control completes the metamemory architecture by linking evaluation of memory to regulation of memory behavior.

## 5. Boundaries
### Owns
Owns intentional regulation of memory processes and strategies.

### Defers
Metamemory owns the broader domain; self-regulated learning belongs to Chapter 1.7 when the focus is learning regulation rather than memory-specific control.

## 6. Key Principles
- Memory can be deliberately regulated.
- Effective control depends on accurate monitoring.
- Control is constrained by cognitive and situational resources.

## 1.8.69 Amnesia

## 1. Purpose
Explain clinically significant impairment of memory that cannot be reduced to ordinary forgetting.

## 2. Definition
Amnesia is a clinically meaningful disturbance of memory involving impaired acquisition, retention, retrieval, or access to information, depending on the condition.

## 3. Core Understanding
Amnesia is heterogeneous. Different conditions can selectively affect new learning, past memories, particular memory systems, or broader cognitive functioning.

### Types and causes
Amnesia can follow brain injury, neurological disease, substance effects, psychological conditions, or other causes. The pattern of impairment is more informative than the label alone.

### Boundary conditions
Amnesia is not synonymous with ordinary forgetfulness. Some individuals show severe episodic impairment while retaining procedural learning or other capacities.

### Evidence status
Neuropsychological cases demonstrate that memory systems can dissociate, providing important evidence for the architecture of human memory.

## 4. Relationship to This Chapter
Amnesia provides the principal clinical entry point for disorders of memory function.

## 5. Boundaries
### Owns
Owns clinically significant memory impairment as a broad neuropsychological phenomenon.

### Defers
Anterograde and retrograde amnesia specify temporal patterns; diagnostic classification and clinical disorders belong to Chapter 1.19.

## 6. Key Principles
- Amnesia has multiple forms and causes.
- Different memory systems can be selectively impaired.
- Clinical memory loss is not equivalent to ordinary forgetting.

## 1.8.70 Anterograde amnesia

## 1. Purpose
Explain impairment in forming or retaining new memories after the onset of a condition.

## 2. Definition
Anterograde amnesia is impaired ability to form or retain new memories for events or information occurring after the onset of the memory-impairing condition.

## 3. Core Understanding
The impairment can be selective rather than global. Some patients show severe difficulty forming new episodic memories while retaining language, general knowledge, short-term maintenance, or procedural learning to varying degrees.

### Mechanism
The underlying mechanism depends on the cause and can involve disruption of encoding, consolidation, or related neural systems.

### Boundary conditions
Anterograde impairment should not be inferred merely from poor immediate performance; assessment must distinguish attention, working memory, and long-term learning.

### Evidence status
Classic neuropsychological cases provide strong evidence that new episodic learning can be impaired while other forms of learning remain relatively preserved.

## 4. Relationship to This Chapter
Anterograde amnesia is the forward-looking temporal form of clinical memory impairment.

## 5. Boundaries
### Owns
Owns impairment in acquiring or retaining new information after onset.

### Defers
Amnesia is the broader clinical category; retrograde amnesia concerns memories from before onset.

## 6. Key Principles
- Anterograde amnesia concerns new learning after onset.
- It can selectively affect memory systems.
- Immediate attention and working memory must be distinguished from long-term acquisition.

---

## 1.8.71 Retrograde amnesia

## 1. Purpose
Explain impaired access to memories formed before the onset of a memory-impairing condition.

## 2. Definition
Retrograde amnesia is impaired ability to retrieve or retain memories from before the onset of a condition.

## 3. Core Understanding
Retrograde loss can vary in temporal extent and can affect different kinds of memory unevenly. In some conditions, memories from periods closer to the onset are more vulnerable than remote memories.

### Mechanism
The pattern depends on the underlying cause and may involve disruption of stored representations, retrieval pathways, or the ability to reconstruct prior events.

### Boundary conditions
Retrograde amnesia does not necessarily erase all forms of prior learning. Procedural skills and general knowledge can sometimes remain relatively preserved.

### Evidence status
Clinical and neuropsychological evidence demonstrates that access to past memories can be disrupted independently of all future learning ability.

## 4. Relationship to This Chapter
Retrograde amnesia is the backward-looking temporal form of clinical memory impairment.

## 5. Boundaries
### Owns
Owns impairment of memories formed before onset.

### Defers
Anterograde amnesia concerns new learning after onset; autobiographical memory describes personal memory rather than clinical impairment.

## 6. Key Principles
- Retrograde amnesia concerns pre-onset memories.
- Loss can be selective in time and memory type.
- Clinical patterns depend on cause and mechanism.

## 1.8.72 Memory and identity

## 1. Purpose
Explain how memory contributes to continuity, self-understanding, and personal identity.

## 2. Definition
Memory and identity refers to the relationship between remembered personal experiences and the construction, maintenance, and revision of a person's sense of self across time.

## 3. Core Understanding
Autobiographical memories provide information about past actions, relationships, values, and experiences that can support a coherent personal narrative. Identity can also influence which memories are retrieved and how they are interpreted.

### Mechanism
Memory contributes to perceived continuity by connecting past and present selves. Current goals and self-beliefs can guide retrieval, making some memories more accessible because they fit current identity.

### Boundary conditions
Personal identity is not reducible to memory. People can retain a sense of self despite substantial memory impairment, and memory itself can change without eliminating personal continuity.

### Evidence status
The relationship is strongly supported conceptually and empirically, but identity is a multidimensional construct with social, bodily, relational, and personality components beyond memory.

## 4. Relationship to This Chapter
This Topic places memory within the broader psychological function of maintaining a sense of personal continuity.

## 5. Boundaries
### Owns
Owns the memory-centered contribution to identity and continuity.

### Defers
Self-awareness and personality own broader self and identity constructs; autobiographical memory owns the memory system involved.

## 6. Key Principles
- Memory contributes to personal continuity.
- Identity also shapes memory.
- Personal identity cannot be reduced to memory alone.

## 1.8.73 Emotion and memory

## 1. Purpose
Explain how emotional processes can influence memory formation, retrieval, and reconstruction.

## 2. Definition
Emotion and memory refers to the bidirectional relationship in which emotional states and emotional significance influence memory processes, while remembered experiences can also evoke or modify emotion.

## 3. Core Understanding
Emotion can influence attention, encoding, consolidation, retrieval, and the subjective significance of memories. Effects differ between emotional arousal, emotional valence, mood, and the specific memory task.

### Mechanism
Emotionally significant information may receive enhanced attention or consolidation under some conditions, while intense emotion can also narrow attention or impair memory for peripheral details.

### Boundary conditions
There is no single rule that "emotion improves memory." Effects depend on arousal, timing, material, task demands, congruence, and whether central or peripheral information is being tested.

### Evidence status
Emotion–memory interactions are robust but complex; simple claims of universal emotional enhancement are not supported.

## 4. Relationship to This Chapter
This Topic captures the major cross-link between memory and affect while preserving separate ownership of emotion.

## 5. Boundaries
### Owns
Owns memory processes specifically as influenced by and influencing emotion.

### Defers
Emotion itself belongs to Chapter 1.13; stress-related effects belong here only as memory consequences of stress and defer broader stress processes to Chapter 1.18.

## 6. Key Principles
- Emotion can alter multiple stages of memory.
- Emotional arousal can enhance some information while impairing other details.
- Effects depend strongly on timing and task conditions.

## 1.8.74 Stress and memory

## 1. Purpose
Explain how stress can alter encoding, consolidation, retrieval, and memory performance.

## 2. Definition
Stress and memory refers to the effects of psychological or physiological stress responses on memory processes and memory performance.

## 3. Core Understanding
Stress effects are not uniformly harmful or beneficial. Timing is critical: stress before learning, during encoding, shortly after learning, or during retrieval can produce different outcomes.

### Mechanism
Stress-related physiological and attentional changes can alter what is prioritized, how information is consolidated, and how retrieval is controlled. High stress can narrow attention toward salient information while reducing access to less prioritized details under some conditions.

### Boundary conditions
Effects vary with stress intensity, controllability, timing, individual differences, material, and task demands. Chronic stress can have different consequences from brief acute stress.

### Evidence status
Stress–memory relationships are well established but highly context-dependent.

## 4. Relationship to This Chapter
This Topic treats stress specifically as a modifier of memory rather than re-owning the broader stress response.

## 5. Boundaries
### Owns
Owns memory-centered consequences and mechanisms of stress.

### Defers
Stress itself and stress appraisal belong to Chapter 1.18; emotion and memory owns broader affective influences.

## 6. Key Principles
- Stress effects on memory depend strongly on timing.
- Acute and chronic stress should not be treated as interchangeable.
- Stress can enhance some memory components while impairing others.

## 1.8.75 Sleep and memory

## 1. Purpose
Explain the relationship between sleep and memory formation, stabilization, and retrieval.

## 2. Definition
Sleep and memory refers to the effects of sleep and sleep-related processes on memory encoding, consolidation, retention, and later performance.

## 3. Core Understanding
Sleep can support memory after learning, but effects depend on memory type, learning conditions, sleep stage, timing, and comparison condition. Sleep is therefore not simply a universal memory "storage period."

### Mechanism
Sleep may support stabilization and reorganization of newly learned information through coordinated neural and physiological processes. Different sleep stages may contribute differently to different forms of learning.

### Boundary conditions
Sleep cannot compensate for inadequate initial encoding, and not every task shows a large sleep-related benefit. Sleep deprivation can also impair attention and encoding, indirectly harming later memory.

### Evidence status
Sleep-dependent memory effects are supported by substantial experimental research, but precise mechanisms and the unique contribution of particular sleep stages remain active research areas.

## 4. Relationship to This Chapter
This is the **memory-centered owner of the sleep–memory relationship**. Chapter 1.5's **Sleep-dependent memory effects** is a sleep-centered manifestation and defers the general relationship here.

## 5. Boundaries
### Owns
Owns the general relationship between sleep and memory.

### Defers
Sleep architecture and sleep regulation belong to Chapter 1.5; learning mechanisms belong to Chapter 1.7; broader sleep-health effects belong to Chapter 1.18.

## 6. Key Principles
- Sleep can influence memory after learning.
- Effects depend on memory type, timing, and sleep conditions.
- Sleep supports but does not replace effective encoding and learning.

## 1.8.76 Individual differences in memory

## 1. Purpose
Explain why people differ in memory ability, strategy, susceptibility to forgetting, and memory errors.

## 2. Definition
Individual differences in memory are stable or partly stable differences among people in memory capacity, processes, strategies, performance, or susceptibility to memory distortion.

## 3. Core Understanding
People vary in working-memory capacity, learning efficiency, retrieval strategies, autobiographical specificity, metamemory calibration, and vulnerability to particular memory errors.

### Sources of variation
Differences can reflect prior knowledge, attention, strategy use, sleep, stress, motivation, development, neurological factors, and other biological and environmental influences. A single memory test cannot explain all sources of individual variation.

### Boundary conditions
Individual differences are task-specific. A person who performs well on one memory measure may not have an equally large advantage on another because memory systems and tasks differ.

### Evidence status
Reliable individual differences exist, but their causes and cross-task generality are complex and should not be reduced to a single "memory ability."

## 4. Relationship to This Chapter
This Topic captures variation across the complete memory architecture without re-owning the general construct of individual differences.

## 5. Boundaries
### Owns
Owns memory-specific variation in performance, strategy, process, and susceptibility to memory effects.

### Defers
Chapter 1.1 owns general individual differences; Chapter 1.14 owns personality-related individual differences; biological sources belong to Chapter 1.3.

## 6. Key Principles
- People differ across multiple memory dimensions.
- Memory ability is task-specific rather than a single universal capacity.
- Individual variation reflects interacting cognitive, biological, developmental, and contextual factors.
