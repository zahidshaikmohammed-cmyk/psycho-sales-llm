# 1.1.27 — Psychological Processing

## 1. Purpose

Psychological processing describes the transformation of information and internal conditions into representations, evaluations, decisions, and responses. It provides the core process layer between input and output.

## 2. Definition

Psychological processing is the set of operations through which a psychological system detects, selects, represents, interprets, evaluates, integrates, stores, or uses information and internal signals.

## 3. Core Understanding

Processing is selective rather than complete. Humans cannot give equal depth to all available information. Attention, prior knowledge, goals, emotion, and context influence what is processed and how.

Processing can be rapid or slow, automatic or controlled, conscious or less accessible. It can transform sensory input into representations, combine new information with memory, evaluate alternatives, or prepare responses.

Processing is often recursive. New information can alter interpretation, and the resulting interpretation can change what is attended to next. Feedback therefore makes processing dynamic.

## 4. Relationship to This Chapter

Processing connects stimulus, attention, interpretation, representation, evaluation, response selection, and feedback. It is a central bridge in the chapter's processing architecture.

## 5. Boundaries

### Owns
- General psychological processing.
- Transformation and integration of information at the architectural level.

### Defers
- Specific processes → canonical chapters.
- Biological processing → 1.3.

## 6. Key Principles

1. Psychological processing transforms and uses information.
2. Processing is selective and capacity-limited.
3. Processing can be automatic or controlled.
4. Prior knowledge, goals, states, and context influence processing.
5. Processing can involve feedback and repeated updating.
