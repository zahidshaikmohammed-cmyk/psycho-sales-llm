# 1.1.20 — Behavior–Environment Transaction

## 1. Purpose

Behavior can change the environment that later influences behavior. This transactional relationship is important because it moves beyond one-way explanations in which the environment causes behavior but behavior never changes the environment.

## 2. Definition

A behavior–environment transaction is a reciprocal process in which behavior alters environmental conditions, and those altered conditions subsequently influence later behavior.

## 3. Core Understanding

Transactions can be immediate or extended. A person speaks and another person responds; the response changes the social environment and affects what the person does next. Repeated behaviors can also shape relationships, routines, opportunities, and social expectations over longer periods.

Transactions can involve selection, evocation, and modification. People may select environments that fit existing tendencies, evoke reactions from others through their behavior, or actively modify environments. These processes can reinforce patterns or create opportunities for change.

A transaction is not necessarily intentional. A behavior can change an environment without the person planning that effect. Nor does every behavioral consequence produce stable environmental change.

## 4. Relationship to This Chapter

This concept links behavior, environment, feedback, reciprocal causation, adaptation, and person–environment interaction.

## 6. Key Principles

1. Behavior can change the conditions that later influence behavior.
2. Person and environment can form feedback loops.
3. Transactions can be intentional or unintentional.
4. Repeated transactions can stabilize or change behavioral patterns.
5. Transactional explanations are reciprocal, not simply one-way.
