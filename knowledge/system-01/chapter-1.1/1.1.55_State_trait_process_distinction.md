# 1.1.55 — State–Trait–Process Distinction

## 1. Purpose
This distinction prevents three different levels of psychological description from being confused: current conditions, enduring tendencies, and ongoing operations.

## 2. Definition
A state is a current psychological condition; a trait is a relatively enduring individual difference; a process is an operation or change occurring over time.

## 3. Core Understanding

The state–trait–process distinction is a way to avoid category errors. A state concerns current condition; a trait concerns relatively enduring variation; a process concerns an operation or change. One psychological phenomenon can be studied at more than one of these levels depending on the question.

For example, anxiety can be treated as a current state, anxiety proneness as a trait-like tendency, and threat appraisal as a process. These can interact: a trait can increase the likelihood of a state, the state can change processing, and repeated processes can contribute to longer-term patterns.

The distinction is not absolute. Some constructs have state and trait components, and some processes become stable through learning. Scientific writing should therefore specify the level being discussed rather than assuming the label has one universal meaning.

## 6. Key Principles
1. State, trait, and process describe different psychological levels.
2. A trait can influence states and processes.
3. Processes can change states.
4. The categories should not be treated as rigid universal boxes.
