# 1.1.51 — Functional Explanation

## 1. Purpose
Functional explanation asks what role a psychological process or behavior serves within a system, without assuming that the function alone identifies its mechanism.

## 2. Definition
A functional explanation describes how a psychological phenomenon contributes to a system's activity, regulation, adaptation, or goal-related operation.

## 3. Core Understanding

Functional explanations ask what a process or behavior contributes to a system. A behavior can help obtain a resource, avoid a threat, communicate information, maintain a relationship, or regulate internal conditions. These are functional descriptions, not automatic claims about conscious purpose.

The same behavior can serve different functions in different contexts. Silence can support concentration in one setting and social avoidance in another. Conversely, different behaviors can accomplish the same function. This is why function should not be inferred from form alone.

Functional explanation also differs from evolutionary explanation. Saying that a behavior currently helps a person cope is not the same as claiming that it evolved because it increased reproductive success. These are different explanatory questions.

A functional account should identify evidence linking the behavior or process to the proposed outcome. A plausible function is not established merely because it sounds adaptive.


## 4. Relationship to This Chapter
Functional explanation complements structural, process, and mechanistic explanation.

## 5. Boundaries
### Owns
- Functional explanation as a level of explanation.
### Defers
- Specific functions → relevant domains.

## 6. Key Principles
1. Functional explanation asks what a phenomenon contributes.
2. Function does not automatically identify mechanism.
3. Function can vary with context.
4. Functional claims require evidence.
