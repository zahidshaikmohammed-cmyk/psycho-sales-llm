# 1.1.53 — Process Explanation

## 1. Purpose
Process explanation describes change and operation over time. It is necessary when a static description cannot explain how an outcome develops.

## 2. Definition
A process explanation accounts for a psychological phenomenon by describing the sequence, transformation, interaction, or temporal operation through which it occurs.

## 3. Core Understanding

Process explanation describes how a psychological phenomenon unfolds. It can specify stages, transformations, feedback loops, or interactions through which an outcome develops.

A process can be rapid or extended and may contain automatic and controlled components. For example, learning can involve exposure, encoding, change in association, retrieval, feedback, and later performance. Not every process follows the same sequence.

Process models are useful because they generate predictions about timing and intermediate events. They can therefore be tested by measuring what happens before, during, and after an outcome.

A process description should not invent hidden stages merely to make a story complete. Each proposed component should have conceptual and empirical justification.


## 4. Relationship to This Chapter
Process explanation connects processing, temporal dynamics, mechanisms, action, and change.

## 5. Boundaries
### Owns

## 6. Key Principles
1. Process explanations describe how psychological activity unfolds.
2. Temporal order can matter.
3. Processes can include feedback and interaction.
4. Proposed stages require evidence.
