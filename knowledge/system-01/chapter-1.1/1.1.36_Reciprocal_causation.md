# 1.1.36 — Reciprocal Causation

## 1. Purpose
Reciprocal causation captures situations in which variables influence one another over time. It prevents psychology from treating person, behavior, and environment as one-way causes.

## 2. Definition
Reciprocal causation is a dynamic causal relationship in which changes in one component can influence another, while changes in the second can subsequently influence the first.

## 3. Core Understanding
A person's behavior can change the social environment, which changes later behavior. Beliefs can influence behavior, and behavioral outcomes can provide evidence that changes beliefs. The relationship unfolds over time.

Reciprocity does not mean every variable always causes every other variable. A reciprocal model must specify which pathways are supported and under what conditions.

## 4. Relationship to This Chapter
It links person, environment, behavior, feedback, learning, and adaptation.

## 6. Key Principles
1. Causes can become consequences and later causes.
2. Reciprocal relationships unfold over time.
3. Reciprocity must be demonstrated, not assumed.
4. Feedback is a common pathway for reciprocal influence.
5. Reciprocal causation does not mean universal mutual causation.
