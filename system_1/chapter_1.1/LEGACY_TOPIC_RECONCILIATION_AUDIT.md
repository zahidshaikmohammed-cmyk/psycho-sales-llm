# SYSTEM 1 — CHAPTER 1.1
## Legacy Topic Reconciliation Audit

**Purpose:** Ensure that no meaningful topic from the previous System 1 Chapter 1.1 is silently lost during the rebuild.

The legacy material contained a 25-topic chapter text and a separate 55-topic index. They were not internally consistent. This audit therefore treats both as source material rather than as canonical authority.

| Legacy concept | Rebuild disposition | Reason |
|---|---|---|
| The Architecture of the Human Mind | **Retained — Chapter 1.1** | Direct subject of the rebuilt chapter. |

| Attention | **Retained — later System 1 attention chapter; referenced architecturally where needed** | Attention is a core mechanism but deserves detailed ownership outside the architecture chapter. |
| Beliefs | **Retained — cognition/belief-related System 1 ownership; belief representations referenced in 1.1** | General belief formation and change are broader than architecture. |
| Emotions | **Retained — emotion chapter; affective system owned architecturally in 1.1** | 1.1 establishes the system; later chapter explains the mechanism. |
| Memory | **Retained — memory chapter; memory system owned architecturally in 1.1** | Avoids duplicate detailed memory ownership. |

## Legacy 55-topic index reconciliation

The previous 55-topic Chapter 1.1 index is also preserved conceptually through the rebuilt ontology:

- Human mind and mental architecture → foundational ontology.
- Conscious/preconscious/unconscious → awareness and consciousness.
- Cognitive/emotional/motivational/perceptual/memory/learning/behavior/self/regulatory/social systems → core psychological systems.
- Information processing and mental/cognitive processing → information-processing architecture.
- Mental representation, internal representation, mental models → representation and knowledge structure.
- Psychological/cognitive/emotional/motivational/behavioral/executive/adaptive/integrative functions → psychological functions and control.
- Mind–brain, neural basis, biological foundations, environment, nature–nurture, gene–environment → mind–brain–body–environment section.
- Integration, modularity, plasticity, stability, flexibility, automaticity, emergence → fundamental properties.
- Systems perspective, dynamic systems, system interaction, biopsychosocial model, human functioning → architectural frameworks.

## Important result

No legacy concept is being deleted from the encyclopedia merely because it is removed from Chapter 1.1.

The rebuild separates:

**architectural ownership**

from

**process ownership**

from

**applied sales ownership**.

That is necessary to maintain the One Concept = One Canonical Owner rule.

10. Does keeping it create duplication?
