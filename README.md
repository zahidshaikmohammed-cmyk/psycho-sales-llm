# PSYCHO SALES

A canonical, ontology-first psychological knowledge system for sales, persuasion, buyer behavior, negotiation, performance, and AI training.

## Build principle

**Ontology first → audit → lock → write → validate → version.**

The knowledge base is designed for two audiences at the same time:

1. Human readers who need extremely clear explanations.
2. Language models that need precise, bounded, reusable knowledge objects.

The project follows **One Concept = One Owner**. Related concepts may be referenced across systems, but canonical ownership is assigned once.

The repository is being rebuilt from System 1 onward.

- Knowledge generation: not yet started — ontology audit precedes writing

## Quality target

Simple language must never mean shallow reasoning.

Every topic must be:
- scientifically grounded
- conceptually deep
- easy to understand on first reading
- explicit about boundaries
- free from unnecessary duplication
- suitable for structured LLM retrieval and training
