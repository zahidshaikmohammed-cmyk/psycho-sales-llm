# 6. IMPORTANT OWNERSHIP PATTERN

A raw duplicate-name scan across a large psychology architecture will produce many repeated words.

That does NOT automatically mean there are duplicate canonical owners.

The writer must distinguish:

### True duplicate owner

Two Topics claim the same construct at the same conceptual level.

**Action:** remediate before writing.

### Specialized manifestation

A broader construct exists elsewhere, while the current Topic owns a clearly narrower manifestation.

**Action:** keep the current Topic and explicitly define the boundary.

### Relationship/reference

A Topic mentions another construct because the relationship matters.

**Action:** reference/defer it. Do not re-own it.

### Application-context specialization

The same general word appears in different domains with different canonical meanings.

**Action:** preserve distinct ownership if the architecture explicitly distinguishes them.

Never rename Topics merely because their names contain similar words.

## 12. Evidence standard

Preserve epistemic status.

Use clear distinctions:

- **Definition:** “X means...”
- **Established finding:** “Research consistently shows...”
- **Association:** “X is associated with...”
- **Causal evidence:** “Evidence supports the conclusion that...”
- **Theory/model:** “According to...”
- **Interpretation:** “This suggests...”
- **Uncertainty:** “It remains unclear whether...”

Never turn correlation into causation.

Never turn theory into fact.

Never hide uncertainty.

If another Topic owns it, defer it.

If evidence is insufficient, qualify it or state the uncertainty.

If yes, shorten it.

> Can it be made shorter without increasing ambiguity or creating a false impression?

If yes, shorten it again.

Stop at minimum sufficient form.
