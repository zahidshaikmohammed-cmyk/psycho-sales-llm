# PSYCHO SALES — CHAPTER MAP & CROSS-SYSTEM OWNERSHIP AUDIT

## Status

**AUDITED — ARCHITECTURE-LEVEL LOCK CANDIDATE**

This document defines the chapter boundaries that must be respected when topic ontologies are built.

The central rule is:

> One Concept = One Canonical Owner.

A later system may describe how an earlier concept operates inside its own domain. That is application, not re-ownership.

# Critical boundary tests

## Test A — General construct versus sales application

If a topic can be understood without a sales context and describes a general human psychological mechanism, its canonical owner belongs in System 1 unless a later system has a clearly narrower domain phenomenon.

## Test B — Application does not create ownership

A chapter may explain:
- how attention works during a cold call;
- how persuasion changes buyer judgments;
- how motivation affects salesperson performance.

Those explanations do not transfer ownership of attention, persuasion, or motivation.

## Test C — Domain-specific phenomena may have distinct owners

A sales objection is not merely "resistance" with a sales label. It is a sales interaction phenomenon with a distinct functional context. System 7 may therefore own the sales-specific phenomenon while System 4 retains general persuasion resistance.

## Test D — Scientific models do not own constructs

If a model explains motivation, the model belongs in System 10. Motivation itself remains owned by its canonical psychological system.

## Test E — Intelligence does not create psychology

System 11 can infer relationships among canonical concepts. It cannot create a new concept merely because that concept is useful for a reasoning workflow.

# Architecture decision

The architecture is considered structurally complete at the system-and-chapter level.

**Decision: ELIGIBLE FOR MASTER LOCK.**

Topic-level ownership must still be audited while each system ontology is built. A topic-level conflict discovered later must be resolved by changing the topic's owner or wording rather than weakening the One Concept = One Owner rule.
